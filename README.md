This is a cluster deployer tool, it deploys a cluster that is selfextending

The finalizaton step disables ur cluster masterkeys and at that point your cluster signers are the masters in the house.

There's an ai system here that tags files that you upload, first they suggest tags then they vote for tags in hotpocket and then the winning tags get set to the files.


There's a RAID like system, you can replicate files to instances when you upload, you decide how many instances u want to upload to. Hotpocket handles file integrity when you download.

Marvelous system, but needs some fixing here and there.
